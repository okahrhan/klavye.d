# klavye.d
on parmak

Tek dosyalık (`index.html`) 10 parmak klavye antrenmanı. Tarayıcıda açman yeterli, kurulum yok.

- **Düzenler:** Türkçe Q / Türkçe F (işletim sistemindeki klavye düzenin seçtiğinle aynı olmalı)
- **Seviyeler:** 1 orta satır · 2 + üst satır · 3 tüm harfler · 4 + rakamlar ve noktalama
- **El seçimi:** iki el / sadece sol el / sadece sağ el (diğer elin tuşları rehberde soluklaşır)
- **Sonsuz akış:** 3–6 karakterlik anlamsız diziler, süre sınırı yok
- **Canlı istatistik:** WPM / DKS (tıklayarak değiştir), doğruluk, seri, en iyi seri, aktif süre
- **Ses:** Web Audio API ile üretilir; doğru seri ilerledikçe perde yükselir, hatada sıfırlanır
- **Efektler:** seri kademeleriyle renk değiştiren sayaç, parçacıklar, eşik afişleri (25, 50, 75, 100…), seri kırılınca sarsıntı — `efekt` düğmesiyle kapatılabilir
- **Klavye rehberi:** sıradaki tuş, gerekiyorsa shift ve hangi parmakla basılacağı

Kısayollar: `Esc` / `Tab` yeniden başlat · `Ctrl+Backspace` kelimeyi sil
